# MARMAdrive

Проєкт бекенд-сервісу для курсу розробки. Розвивається поступово, від заняття до заняття.

## Що це

MARMAdrive — це спеціалізований бекенд-сервіс для зберігання та організації закладок і посилань для професійного сомельє та дегустатора пива (Сергій, 40 років). Сервіс вирішує проблему хаотичного збереження важливих джерел (рідкісні сорти, технічні специфікації, крафтові броварні) у месенджерах і закладках. MARMAdrive забезпечує приватність особистої бази посилань за замовчуванням і надає можливість генерувати публічний доступ (Google Drive style short-links) для шерингу добірок із колегами та клієнтами, а також швидкий пошук і дашборд.

## Як запустити

Сервіс уже працює як служба systemd на сервері й автоматично піднімається після перезавантаження або аварійного збою:

```bash
systemctl --user status club-api      # стан служби
systemctl --user restart club-api     # перезапустити після зміни коду
journalctl --user -u club-api -n 30   # останні рядки логу, якщо щось не так
```

Параметри служби:
- Мій порт: 9533
- Час відновлення після збою (RestartSec): 3 секунди

Перевірити, що відповідає (локально та ззовні):

```bash
curl http://127.0.0.1:9533/api/ping
curl http://91.219.61.4/u/artem.g15/api/about
curl http://91.219.61.4/u/artem.g15/api/user
curl http://91.219.61.4/u/artem.g15/api/plan
```
