# Повний бекап проєктів із сервера (artem.g15)

Ця гілка містить повну структуру всіх розробок та конфігурацій учня Масьома Артем із навчального сервера 91.219.61.4.

---

## 📂 Структура репозиторію

### 1. pp/ — Головний проєкт курсу: MARMAdrive
- **Бекенд:** FastAPI (main.py)
- **База даних:** SQLite (db.py, init_db.py)
- **ШІ-інтеграція:** LLM клієнт (llm.py)
- **Telegram-бот:** aiogram (ot.py, 	ry_bot.py)
- **Розгортання:** deploy.sh
- **Опис та маніфест:** Brief.md, project.yaml
- **HTML сторінка:** www-index.html

### 2. 	elegram_openrouter_bot/ — Автономний Telegram-бот з OpenRouter
- Дворівневе автоматичне стиснення контексту (підсумок + останні повідомлення)
- Збереження контексту в SQLite (WAL-режим)
- Інтеграція з моделями через OpenRouter API

### 3. server_monitor_bot/ — Бот системного моніторингу сервера
- Моніторинг завантаження CPU, RAM, диска
- Сповіщення при перевищенні лімітів

### 4. www/ — Персональний сайт-візитка
- index.html: адаптивна веб-сторінка з описом навичок та посиланнями на API.

### 5. systemd/ — Конфігурації системних служб
- club-api.service — служба запуску API MARMAdrive на FastAPI/uvicorn
- 	elegram-bot.service — служба автозапуску Telegram-бота з OpenRouter
- server-monitor-bot.service — служба бота моніторингу
