# Telegram-бот з OpenRouter та інтелектуальним стисненням контексту

Потужний, економічний та автономний Telegram-бот на Python (aiogram 3), який взаємодіє через OpenRouter API та оптимізує витрати токенів за допомогою дворівневого автоматичного стиснення контексту.

---

## 🎯 Реалізований функціонал

1. **Особисті повідомлення та українська мова:**
   - Працює виключно у Direct Messages (приватних чатах).
   - Відповідає суворо українською мовою.

2. **Індивідуальна пам'ять у SQLite (`aiosqlite`):**
   - Кожен користувач має повністю відокремлену історію.
   - WAL-режим SQLite гарантує збереження контексту, підсумку та лічильника при аварійних зупинках або перезавантаженнях сервера.

3. **Кнопка «🔄 Новий чат»:**
   - Зручна клавіатура та команди `/newchat` / `/start`.
   - Повністю скидає активну історію, видаляє підсумок та скидає лічильник повідомлень поточного користувача. Інші користувачі залишаються незмінними.

4. **Дворівневе автоматичне стиснення контексту:**
   - **Тригер 1 (за лічильником):** Кожні 50 повідомлень (користувач + бот).
   - **Тригер 2 (за лімітом токенів):** Автоматичний запуск при наближенні контексту до порогу `TOKEN_TRIGGER_THRESHOLD=8000` токенів, навіть якщо 50 повідомлень ще не набралося.
   - **Механізм:** Попередній підсумок та стара історія об'єднуються у лаконічний підсумок (до 150 слів / маркований список), а останні 4 повідомлення (2 пари) залишаються дослівно. Старі повідомлення відкидаються.
   - **Стійкість до збоїв:** Якщо запит на стиснення не вдався (помилка мережі чи API), **історія не видаляється**, бот продовжує роботу та повторює спробу при наступному повідомленні.

5. **Безпека ключів:**
   - Ключі зберігаються у файлі `.env` з правами доступу `chmod 600` (читання/запис тільки для власника).
   - Токени та ключі маскуються і **ніколи не виводяться у журнали** (journalctl).

6. **Системна служба systemd:**
   - Назва: `telegram-bot.service`
   - Робота від окремого непривілейованого користувача (`artem.g15`).
   - Автозапуск при завантаженні системи (`WantedBy=multi-user.target`).
   - Автоматичний перезапуск при падінні (`Restart=always`, `RestartSec=5s`).
   - Не змінює та не зачіпає жодних сторонніх служб сервера.

## 🛠 Команди керування ботом на сервері

| Дія | Команда |
| :--- | :--- |
| **Перевірка стану** | `systemctl --user status telegram-bot` |
| **Перегляд журналів у реальному часі** | `tail -f /home/artem.g15/telegram_openrouter_bot/bot.log` |
| **Перегляд останніх 50 рядків логів** | `tail -n 50 /home/artem.g15/telegram_openrouter_bot/bot.log` |
| **Зупинка бота** | `systemctl --user stop telegram-bot` |
| **Перезапуск бота** | `systemctl --user restart telegram-bot` |
| **Запуск бота** | `systemctl --user start telegram-bot` |
| **Запуск тестів перевірки** | `cd /home/artem.g15/telegram_openrouter_bot && ./venv/bin/python verify_all.py` |
